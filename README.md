# power-BI-dashboard
This Power BI dashboard analyzes the social media and customer engagement performance of different sports products across multiple months and years. The project focuses on tracking important KPIs such as Conversion Rate, Views, Clicks, Likes, and Customer Ratings to help businesses understand product popularity and marketing effectiveness. 
# Sports Product Performance Dashboard | Power BI

## Overview
This Power BI dashboard project analyzes the performance of sports products using social media engagement metrics and customer reviews. The dashboard helps businesses monitor product popularity, customer interaction, and conversion trends.

---

## Dashboard Features

- Conversion Rate Analysis
- Views, Clicks, and Likes Tracking
- Customer Rating Analysis
- Product-wise Performance Comparison
- Monthly Trend Analysis
- Interactive Filters and Slicers

---

## KPIs Included

- Conversion Rate
- Total Views
- Total Clicks
- Total Likes
- Average Customer Rating

---

## Tools & Technologies

- Power BI
- DAX
- Data Modeling
- Data Visualization
- Power Query

---

## Insights Generated

- Products with highest conversion rates
- Monthly engagement fluctuations
- Best-rated products
- Customer interaction trends
- Product performance comparison
